# Contributing to pr-reviewer

Read [Contribute a change](docs/how-to/contribute-a-change.md). It covers the clone, issues and triage labels, test-first work, the pull request template, merge commits and releases.

- To take a fix from the original project, read [Bring in an upstream change](docs/how-to/bring-in-an-upstream-change.md).
- To change code that touches tokens, clones or the AI CLI, read the [security model](docs/explanation/security-model.md).
- To report a bug, open an issue on [worldofgeese/pr-reviewer](https://github.com/worldofgeese/pr-reviewer/issues).
- The maintainers' pr-reviewer daemon watches this repository and reviews pull requests from branches in it. It may skip pull requests from forks, so a missing automated review does not mean something is broken.
